# Chief of Staff

An installed, private, ADHD-friendly assistant for organizing personal life, business priorities, tasks, schedules, follow-ups, and work across AI accounts.

## Project status

Requirements interview and design foundation. The deliverable is an installed app; target platforms and implementation technology are not yet finalized. No application, live account integrations, or notification delivery have been implemented yet.

- [Accepted interactive design reference](design/daylight-design.html)

The design uses sample data and local interactions. Open the design file in a browser; nothing is connected or sent. Daylight is a provisional design name.

## Intended navigation

Today · My tasks · Schedule · Follow-ups · AI work

## Development approach

Reconcile priorities through a short, staged interview. The proposed foundation is an installed daily planner with household/business tasks, reminders, feedback, and personalized duration estimates; then real account connections, supported AI coordination, and deeper business workflows. Keep business and personal account permissions distinct. Record actual integration coverage and never present simulated behavior as live.

See the build prompt for full requirements, acceptance criteria, and open setup questions. There are no application install/run commands until the first implementation milestone selects and scaffolds the stack.
