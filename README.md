# Chief of Staff

A private, ADHD-friendly assistant for organizing personal life, business priorities, tasks, schedules, follow-ups, and work across AI accounts.

## Project status

Planning and design foundation. No application, live account integrations, or notification delivery have been implemented yet.

- [Complete build prompt](docs/BUILD-PROMPT.md)
- [Simple explanation and execution plan](docs/SIMPLE-PLAN.md)
- [Accepted interactive design reference](design/daylight-design.html)

The design uses sample data and local interactions. Open the design file in a browser; nothing is connected or sent. Daylight is a provisional design name.

## Intended navigation

Today · My tasks · Schedule · Follow-ups · AI work

## Development approach

Build the daily planning foundation first, then real email/calendar connections and reminders, then supported AI account coordination and deeper business workflows. Keep business and personal account permissions distinct. Record actual integration coverage and never present simulated behavior as live.

See the build prompt for full requirements, acceptance criteria, and open setup questions. There are no application install/run commands until the first implementation milestone selects and scaffolds the stack.
